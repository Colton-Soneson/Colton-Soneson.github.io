When doing a texture for multiple objects in one blend file to be on a singular texture:
1) Object mode, select all (hit 'a')
2) Hit Ctrl + J to join everything
3) then to edit mode, select all (hit 'a')
4) unwrap menu (hit 'u'), unwrap > smart UV Project
5) make island margin 0.04 to get some spacing 
This makes everything in one texture, which depending on level of detail wanted, can be a lot (look into texture atlas then maybe
to do seperate objects)

Say you want to paint two objects, with two different textures each, then join both into one object and one big texture
This is baking multiple textures into one UV tile

create final image for everything to render to through image editor (just do new image)
Make sure in shader editor, that all the materials have this final image attached as a node, and that node selected
create new UV Map under UV map section of each object, name all "bake", select it on all objects
highlight all objects, no need to join, go into edit mode, uv unwrap to the selected final image
go to the render section, cahnge from EEVEE to cycles, scroll down to bake section, change to diffuse with just color attachment, bake button
